# Tutorial: Quickstart

Get started with MethylGPT in minutes. This notebook walks through loading a pretrained model, extracting embeddings, and visualizing them with UMAP.

## Files

- **`quickstart.ipynb`** -- Interactive notebook with the full quickstart pipeline

## Quick Start

```bash
# 1. Download model and data (from tutorials/ root)
cd tutorials && bash download_data.sh

# 2. Run the notebook
jupyter notebook quickstart/quickstart.ipynb
```

## What You'll Learn

1. Loading a pretrained MethylGPT model
2. Preparing methylation data with DataLoaders
3. Extracting sample-level embeddings
4. Visualizing embeddings with UMAP
